```
B 站视频学习副驾：带时间戳的字幕、大纲、导图与上下文问答
```

### 详细描述

```
看 B 站教学视频时，你是否也有这些困扰：看不懂、跟不上、记不住、找不着？

视频学习副驾把整节视频变成可检索、可提问、可沉淀的知识库——所有内容都锚定到秒级时间戳，点一下就跳回视频原位。

▍核心功能

● 字幕：UP 主字幕 / 平台 AI 字幕 / 手动粘贴，三级自动降级；AI 字幕一键加标点顺句
● 大纲：按字幕生成章节与要点，时间戳吸附真实字幕边界；单章可带反馈重新生成
● 导图：把章节重组成「阶段 → 概念」知识流程图，播放跟随高亮当前概念
● 问答：划词解释、区间问答、自由追问；5 轮对话记忆；回答里的时间戳可点击跳播；支持粘贴题目截图（需多模态模型）
● 笔记：在大纲任意位置记笔记（整章 / 某条要点 / 某个时间点），可展开讨论串、一键「请助教回答」；重新生成大纲后笔记自动按时间归位，永不丢弃
● 沉淀：一键存入 Obsidian；没配置 Obsidian 也能下载 .md（自带来源与标签，任何笔记软件可用）
● 分享：大纲与笔记导出为开放格式文件（vsc-outline），他人可一键导入到同一视频

▍隐私承诺

不设账号、没有服务器、不上传数据：你的全部学习数据只存在本机浏览器。模型请求使用你自己的 API Key 直连服务商。完整说明见隐私政策与开源仓库。

▍开始使用

安装后点工具栏图标打开侧边栏，按「？」帮助里的三步指引配置一次模型即可。费用由你的模型按 token 计费（一集 30 分钟视频的全部功能通常不到 0.1 元）。

开源：github.com/phpvincent/ai-video-driver
```

## 3. 审核注意事项（Developer Dashboard 填写）

### 单一用途说明（Single purpose）

> 在 B 站教学视频页提供侧边栏学习辅助：生成锚定时间戳的字幕大纲、知识导图与上下文问答，并支持笔记与知识库沉淀。

### 权限理由（逐条填写）

| 权限 | 理由文案 |
|---|---|
| storage | 保存用户设置与本地学习数据（大纲/笔记/问答历史），全部存于本机 |
| sidePanel | 学习面板以侧边栏形式与视频并排展示 |
| tabs | 获取当前 B 站视频页信息与播放进度，实现时间戳跳播 |
| host: www.bilibili.com | 注入内容脚本读取当前视频信息（BV号/分P/时长/播放位置） |
| host: api.bilibili.com / *.hdslb.com | 拉取视频字幕与字幕配图，供大纲与导图生成 |
| host: api.deepseek.com / maas.qianwenaiapi.com | 用户配置的模型服务商，发送生成请求（用户自己的 API Key） |
| host: api.duckduckgo.com | 问答时的公开资料检索 |
| host: 127.0.0.1:27123 | 连接用户本机 Obsidian Local REST API 写入笔记（用户配置后启用） |
| optional_host_permissions (https://*/*) | 仅为"自定义模型端点"能力预留：用户保存某个自填端点时，按该域名逐个弹窗申请，未授权不发起任何请求 |
