## 1. 一句话定位（ elevator pitch ）

**B 站教学视频的 AI 学习侧边栏：把一节 40 分钟的课，变成一张能随时跳回原位的地图。**

变体（按场合选用）：

- 10 秒版：看网课卡住了？划一下，问一下，跳回去。
- 30 秒版：它读完整节视频的字幕，生成带秒级时间戳的章节大纲和知识流程图；哪里看不懂就点哪里跳回原位，随时提问，笔记自动挂到对应位置，最后沉淀进你的 Obsidian。
- 一句话反差版：**不是又一个"AI 视频总结工具"**——总结工具给你一段文字，我们给你一张能点回视频的地图。

## 3. 用户痛点与目标客户

### 3.1 四大核心痛点（产品的一切功能都对应其中之一）

| 痛点 | 典型场景 | 对应功能 |
|---|---|---|
| **看不懂** | 老师讲到一个术语/推导，没跟上，后面试题全废 | 划词解释、区间问答、拍题作答 |
| **跟不上** | 2 倍速刷课，信息密度爆炸，笔记记了上句漏下句 | 信息密度预警、密度徽标 |
| **记不住** | 学完就忘，考前想复习"那天那个视频讲的二分查找" | 知识流程图、Obsidian 沉淀 |
| **找不着** | 明明看过，就是找不到在视频第几分钟 | 秒级时间戳：大纲/要点/概念/笔记全部可点击跳播 |

### 3.2 目标客户画像（按优先级）

**Persona 1 · 考研党「小林」**（核心人群）
- 22 岁，每天在 B 站刷 3~4 小时数学/专业课网课，全程 1.5~2 倍速
- 痛：张宇的证明跳了一步就跟不上；想复习"泰勒公式那节"翻遍收藏夹
- 付费意愿：为了上岸可以花小钱（对比：一节网课几百元，本工具一节视频不到 0.1 元）

**Persona 2 · 考公族「May」**
- 26 岁，行测/申论网课，信息密度极高（法律条文、数量关系技巧）
- 痛：做题卡壳时想回看"老师讲这个题型是哪一节"，永远找不到
- 特点：多设备学习（导出导入功能命中她）

**Persona 3 · 转码者「大周」**
- 24 岁，看编程教程（Python/前端/算法），代码在画面里不在字幕里
- 痛：跟着敲代码时反复暂停回拖；面试前想快速过一遍知识点
- 特点：Obsidian/Notion 用户，技术嗅觉灵敏，是**早期传播者**（愿意在技术社区分享）

**反画像（不是我们的用户）**：只想"3 分钟看完一部电影解说"的娱乐向用户；用抖音/快手碎片学习的用户。

## 4. 差异化定位（竞品对照）

| 维度 | AI 视频总结类扩展（Glarity / Sider 等） | 本站 |
|---|---|---|
| 产出 | 一段总结文字 | 章节**地图** + 知识流程图 + 可问答的上下文 |
| 粒度 | 整个视频一段话 | **秒级时间戳锚定**，每个要点可点回原位 |
| 学习动作 | 看完就走 | 划词提问 → 记笔记 → 复习 → 沉淀知识库 |
| 数据归属 | 多数经自家服务器 | **无服务器**，数据不出本机，模型调用直连你自己的 Key |
| 学习闭环 | 无 | 笔记 + Obsidian 沉淀 + 大纲文件交换 |

**一句话钉死差异**：竞品把视频变短，我们把视频**变成可检索、可提问、可沉淀的知识资产**。

## 5. 功能全景（演示素材库 · 每项含画面建议）

> 拍摄通用规范：B 站右侧视频区 + 左侧/右侧扩展面板同框；真实教学视频（考研数学最佳，识别度高）；画面节奏跟着"卡住 → 解决"的叙事走。

### 5.1 字幕三级采集（自动，无感）

- **画面**：打开视频 → 面板自动出现字幕流，无需任何操作
- **动效建议**：字幕逐句上涌的小动画，来源标签（UP 主/AI）淡入

### 5.2 章节大纲（旗舰功能，必拍）

- **画面**：点「生成大纲」→ 分块进度 → 章节卡片依次落入
- **动效建议**：字幕流"结晶"成章节卡片的转场动画（乱序文字 → 收拢成结构）；每个要点旁的 `[mm:ss]` 时间戳做高亮脉冲
- **必拍镜头**：点击某个要点时间戳 → 视频精确跳到那句话开始播放（**这是全产品最核心的 3 秒镜头**）

### 5.3 知识流程图（视觉最出效果）

- **画面**：切到导图 Tab →「阶段 → 概念」两列流程图展开，播放时对应概念高亮跟随
- **动效建议**：导图节点生长动画；随播放进度的高亮"游走"效果；关系边描线动画

### 5.4 卡住就问（冲突→解决的核心叙事）

- **画面**：字幕里划选一个术语 → 弹出解释（含视频语境含义）；提问框输入"这步为什么成立" → 助教结合上下文回答，答案里带 `[mm:ss]` 可点跳转
- **进阶镜头**：贴一张考研真题截图 → 多模态模型作答
- **动效建议**：划词的荧光笔效果；回答里时间戳的"闪回跳播"运镜

### 5.5 笔记 + 请助教回答

- **画面**：在要点上点「记」写一句笔记；点「请助教回答」→ 讨论串里出现助教回复
- **叙事点**：大纲重新生成后笔记**自动归位**、永不丢失（可演示重生成 → 笔记还在）

### 5.6 沉淀与分享

- **画面**：一键「存入 Obsidian」→ 切到 Obsidian 看到带时间戳回链的笔记；或未配置时一键下载 .md
- **分享**：导出 vsc-outline 文件 → 另一台设备导入

## 7. 品牌要素

- **名称**：视频学习副驾（"副驾"隐喻：你是司机，它导航——不说教、不打断、你卡住才出现）
- **主色**：#165dff（品牌蓝）；辅助：#e8f3ff 浅蓝、#f7f8fa 底灰
- **图标**：蓝底圆角方 + 白色播放三角 + 底部时间戳条（"播放 + 时间锚"双符号）
- **语气**：陪伴、专业、克制。像学长，不像销售。**禁用**：革命性、颠覆、最强、秒杀等词
- **绝对禁区的表述**（红线）：不承诺"帮你考上/学会"；不说"完全免费"（模型按 token 计费，要说清）；不弱化"需要自己配 API Key"这一步
