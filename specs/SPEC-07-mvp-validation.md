## 1. 目标与范围

用 1~2 周真实学习，回答一个问题：**"预读字幕 → 大纲导图 → 上下文问答 → 沉淀"这个模式是否值得继续投入。**

**做**：
- 本地使用统计（全部来自 IndexedDB，数据不出本机）：每个视频的大纲跳转次数、划词次数、区间提问次数、自由提问次数、存库次数、字幕来源、token 消耗
- 设置页"验证期报告"：一键生成统计汇总（Markdown），可存入 Obsidian
- 每个视频看完后的一题回顾（可跳过）："这次看视频中，切出去搜索的次数比以往 ① 明显少 ② 差不多 ③ 更多"
- 验证结束由父 agent 汇总报告，用户按判定规则拍板

**不做**：远程上报；新增功能。验证期发现的问题记入 EVOLUTION-ROADMAP 或新立 spec。

## 4. 判定指标（开工前固定，验证期内不修改）

| 指标 | 继续 | 调整 | 放弃 |
|---|---|---|---|
| 完成学习的视频数 | ≥ 10 | 5~9 | < 5（主动弃用） |
| 字幕一级通道命中率 | ≥ 80% | 60%~80% | < 60% 且 ASR 未上线 |
| 平均每视频大纲/导图跳转次数 | ≥ 3 | 1~3 | < 1 |
| 平均每视频划词 + 区间提问次数 | ≥ 3 | 1~3 | < 1 |
| 回顾问卷"明显少"占比 | ≥ 50% | 25%~50% | < 25% |

判定规则：
- 全部指标落在"继续"或"调整"，且"继续"项 ≥ 3 个 → **继续**，进入 v0.1.x（优先启用薄弱章节标记与密度预警完整版）
- 任一指标落在"放弃" → **调整**，针对该项做根因分析后决定改进或转向
- 三项以上落在"放弃" → **放弃**该模式，复盘结论记入迭代日志
- 用户可基于主观体验推翻判定，须记录理由
